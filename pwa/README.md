# سازمان فروشگاه — نسخهٔ وب (PWA)

نسخهٔ Progressive Web App اپ اندروید «سازمان فروشگاه» — کاملاً فارسی، راست‌به‌چپ و **آفلاین**.

| | |
|---|---|
| نام | سازمان فروشگاه (Mi Negocio Punto de Venta) |
| زبان رابط | فارسی (RTL) · ارقام فارسی · تاریخ شمسی (جلالی) |
| پایگاه داده | IndexedDB مرورگر (قرینهٔ طرح Room اپ اندروید) |
| وابستگی خارجی | **هیچ** — فونت وزیرمتن و همهٔ منابع لوکال‌اند |

## امکانات

- **فروش**: جستجو/اسکن کالا، سبد با ستون‌های «کالا/واحد/تعداد/فی/جمع/حذف»، تخفیف، روش پرداخت (نقدی/کارت/انتقال)، ثبت فاکتور با شماره‌گذاری خودکار و کاهش موجودی
- **خرید**: رسید تامین‌کننده با افزایش موجودی و بروزرسانی قیمت خرید
- **کالاها**: افزودن/ویرایش/حذف، جستجو با نام/بارکد/کد، هشدار کم‌موجودی، جلوگیری از بارکد تکراری
- **گزارش‌ها**: امروز/این ماه/همه — تعداد فاکتور، مجموع فروش، نقدی/بانکی، جمع خرید، سود ناخالص، پرفروش‌ترین‌ها
- **اسکن بارکد**: با `BarcodeDetector` API (کروم اندروید) + ورود دستی به‌عنوان جایگزین + چراغ‌قوه (در صورت پشتیبانی)
- **تنظیمات**: نام فروشگاه، پشتیبان‌گیری/بازیابی JSON، داده‌های نمونه، پاک‌کردن داده‌ها
- **PWA**: نصب روی موبایل/دسکتاپ، آفلاین کامل پس از اولین بازدید، صفحهٔ آفلاین جایگزین

## ساختار فایل‌ها

```
pwa/
├── index.html          صفحهٔ اصلی (پوستهٔ برنامه)
├── manifest.json       مانیفست PWA
├── service-worker.js   کش آفلاین (pos-v1؛ precache + runtime)
├── register-sw.js      ثبت Service Worker
├── app.js              منطق برنامه (IndexedDB، نماها، اسکنر، جلالی)
├── styles.css          استایل Material 3 الهام‌گرفته، RTL
├── offline.html        صفحهٔ آفلاین جایگزین
├── icons/              آیکون‌های ۱۹۲/۵۱۲ (عادی + maskable)
├── fonts/              وزیرمتن (Regular/Medium/SemiBold/Bold) + مجوز OFL
└── README.md           همین فایل
```

## اجرای سرور تست

از ریشهٔ مخزن:

```bash
python3 serve_pwa.py                # http://0.0.0.0:8080
python3 serve_pwa.py --port 9000    # پورت دلخواه
python3 serve_pwa.py --https        # HTTPS با گواهی self-signed
```

فقط پایتون ۳ استاندارد لازم است (بدون pip install).

## تست روی گوشی (همان Wi-Fi)

1. سرور را روی سیستم خود اجرا کنید: `python3 serve_pwa.py --https`
2. URL نمایش‌داده‌شده در بنر (LAN URL) را روی گوشی باز کنید
   (مثل `https://192.168.1.5:8080`)
3. چون گواهی self-signed است، Chrome هشدار می‌دهد:
   **پیشرفته ← ادامه به سایت (ناامن)**
4. برای اسکن بارکد و دوربین، حتماً `https` لازم است (یا `localhost`)

اگر HTTPS ممکن نبود:

```bash
adb reverse tcp:8080 tcp:8080     # سپس روی گوشی: http://localhost:8080
```

## نصب PWA روی گوشی

1. صفحه را در **Chrome اندروید** باز کنید
2. منوی ⋮ ← **«Add to Home screen» / «افزودن به صفحه اصلی»**
3. (یا دکمهٔ «نصب برنامه» در نوار بالای برنامه را بزنید)

پس از نصب، برنامه مثل اپ معمولی از صفحه اصلی اجرا می‌شود و **بدون اینترنت** کار می‌کند.

## محدودیت‌های شناخته‌شده

- **Firebase** (ورود، Firestore، اعلان‌ها، Analytics/Crashlytics) در نسخهٔ وب پیاده نشده؛ داده‌ها فقط محلی‌اند (IndexedDB همین دستگاه).
- **AdMob** در PWA وجود ندارد (تبلیغات موبایل مخصوص اپ بومی است).
- **چاپ حرارتی فاکتور/گزارش** (PdfBox) پیاده نشده؛ فقط خروجی پشتیبان JSON داریم.
- `BarcodeDetector` فعلاً در Chrome/Edge اندروید و برخی دسکتاپ‌ها هست؛ در نبودش ورود دستی بارکد کار می‌کند.
- امکانات کامل اپ اندروید مثل مشتریان/تامین‌کنندگان/ویزیتورها/بانک‌ها/چک در این نسخهٔ اولیه PWA نیستند (تمرکز: فروش، خرید، کالا، گزارش).
- داده‌های IndexedDB با پاک‌کردن دادهٔ سایت مرورگر حذف می‌شوند — به‌طور دوره‌ای «خروجی پشتیبان» بگیرید.

## راهبرد کش (برای توسعه‌دهنده)

- `CACHE_NAME = 'pos-v1'` در `service-worker.js`
- استاتیک: **cache-first**؛ ناوبری: شبکه ← کش؛ درخواست‌های Firebase: network-first
- پس از هر تغییر در فایل‌ها، نسخهٔ کش را بالا ببرید (`pos-v2` و…) تا به کاربران برسد
- `skipWaiting + clients.claim` فعال است؛ آپدیت با رفرش صفحه اعمال می‌شود
